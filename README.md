# SalonFlow — Full-Stack Salon Management System

> **Your Beauty. Your Time. Your Salon.**  
> A modern digital platform engineered to simplify salon operations and elevate the customer booking experience. Built with a warm editorial aesthetic and a **Light Blue Color System** (`#7CCBEE`).

[SalonFlow Live Demo](https://salon-management-m1jk.vercel.app/)


## 🌟 Overview

SalonFlow bridges the gap between high-end salon clientele and busy salon operators. It features:
- **Client Discovery & Booking**: Discover bespoke hair, skincare, and bridal rituals, select preferred master stylists, check live calendar availability, and book conflict-free appointments.
- **Executive Salon Management**: A centralized operations dashboard encompassing real-time appointment lifecycles, customer CRM, staff performance & commission calculation, service catalog, inventory stock movements, GST invoicing, loyalty rewards, promo coupons, and Recharts analytics.
- **Strict Design Standards**: Warm cream canvas (`#F9F7F3`), bone surfaces (`#F3F0E8`), rounded pill buttons, subtle shadows, large editorial typography (`Bricolage Grotesque`, `Inter`, `JetBrains Mono`), and the **Light Blue Color System** (zero orange, red, or pink accents).

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7
- **Charts & Data Visualization**: Recharts
- **Celebration Effects**: Canvas Confetti

### Backend
- **Runtime**: Node.js + Express.js + TypeScript
- **Architecture**: Modular REST API (Controllers, Services, Routes, Middleware, Validators)
- **Authentication**: JWT (JSON Web Tokens) with 7-day session validity + bcryptjs password hashing
- **Database**: MongoDB with Mongoose ODM (ObjectIds, Indexes, Compound Indexes, Cascade Updates)
- **Validation & Logging**: Morgan logger & defensive validation

## 🚀 Key Modules & Capabilities

### 1. Public Landing Page
- **Editorial Hero**: Large typography, clean composition, trust metrics (4.9★ rating, 8+ master artists).
- **Curated Services Menu**: Categorized under *Hair, Beauty, Nails, Bridal, Spa* with realistic Indian salon pricing (₹450 to ₹28,000) and durations.
- **Master Stylist Showcase**: Bios, ratings, review counts, experience, and direct booking links.
- **Salon Experience**: Editorial storytelling focusing on autoclave sterilization, cruelty-free prestige products (Olaplex, L'Oréal, Kérastase), and private luxury consultations.
- **Seasonal Offers & Verified Reviews**: Coupon codes (`FIRSTVISIT15`, `HAIRSPA500`, `BRIDAL2026`) and authentic customer testimonials.

### 2. Multi-Step Customer Booking Wizard
1. **Step 1 — Service Selection**: Filter by category, inspect description, price in INR, and duration.
2. **Step 2 — Stylist Picker**: Choose a specific master artist or select *"Any Available Stylist"*.
3. **Step 3 — Date Selection**: Quick 7-day pill selector or custom calendar date picker.
4. **Step 4 — Real-Time Availability**: Backend `/api/appointments/availability` scans stylist schedules, salon hours, and existing bookings to eliminate double-booking.
5. **Step 5 — Guest Details & Coupon Application**: Auto-populates for signed-in guests; validates coupon codes in real-time.
6. **Step 6 — Review & Confirmation**: Summary breakdown with instant booking creation and celebratory confetti.

### 3. Management Dashboard
- **Executive KPIs**: Real-time counters for Today's Appointments, Today's Revenue, Monthly Revenue, Total CRM Customers, Pending, Completed, and Active Staff.
- **Appointments Management**: List view and Day Schedule board with full status lifecycle (*Pending* → *Confirmed* → *Checked In* → *In Progress* → *Completed*).
- **Customer CRM**: Complete profile drawer, visit frequency, lifetime spend, loyalty tier (*Bronze*, *Silver*, *Gold*, *Platinum*), and appointment history.
- **Staff & Stylists**: Rosters, working hours, commission rates (10–15%), salary, and live commission calculation reports.
- **Billing & Tax Invoices**: Itemized invoices with automated 18% GST calculation, multiple payment modes (UPI, Cash, Card, Online), and printable invoice layout.
- **Inventory & Supply Chain**: 30+ luxury salon products with SKU tracking, stock-in/out logging, low-stock threshold alerts, and audit trails.
- **Loyalty Program**: Configurable earning rules (1 point per ₹100 spent) and redemption rules (1 point = ₹1 discount).
- **Promotions & Coupons**: Campaign manager supporting percentage and flat discounts, expiration windows, and usage caps.
- **Analytics & Intelligence**: Area charts for revenue trends, pie charts for payment method distribution, and bar charts for appointment completion ratios.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- [MongoDB](https://www.mongodb.com/) (running on `mongodb://127.0.0.1:27017`)

### 1. Clone the Repository
```bash
git clone https://github.com/jiya306/Salon_Management-.git
cd Salon_Management-
```

### 2. Setup the Backend Server
```bash
cd server
npm install
npm run seed     # Seeds realistic Indian salon data, services, staff, and appointments
npm run dev      # Starts Express REST API on http://localhost:5000
```

### 3. Setup the Frontend Client
In a new terminal window:
```bash
npm install
npm run dev      # Starts Vite development server on http://localhost:5173
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
